# Успею

**Открыть сайт:** https://vkysnasa1.github.io/Uspey/

Сайт и приложение для студентов ТулГУ: считает, **во сколько выходить из дома к первой паре** на автобусе или машине, учитывает погоду, подсказывает, **что надеть**, и **напоминает о выходе**.

Проект по дисциплине «Проектная деятельность».
Команда: Комерилов Григорий (руководитель, интерфейс, уведомления), Кузнецов Артем (данные и логика расчёта), Гончаров Иннокентий (аналитика, дизайн, тестирование).

## Что умеет

- **Загружает расписание с сайта ТулГУ по номеру группы** (tulsu.ru/schedule) на весь семестр: даты, время, аудитории, преподаватели. Можно добавить и свои занятия вручную.
- **Свои пары и скрытие чужих**: свою пару (ВУЦ, секция) можно добавить на все недели и удалить на все недели; пару из расписания ТулГУ, которая не твоя (другая подгруппа по языку, физра), можно скрыть в один день или каждую неделю — с учётом преподавателя, чтобы не задеть свою подгруппу.
- **Перенос на другое устройство** ссылкой: группа, свои пары, скрытые занятия, адреса и пробки.
- **Мои адреса**: можно сохранить несколько адресов и подписать их («Дом», «Работа», «Общежитие»…), переключаться одной кнопкой на главном экране; маршруты для каждого адреса считаются один раз и запоминаются.
- **Сам подбирает транспорт до корпуса**: по адресу дома находит остановки, автобусы, троллейбусы и трамваи Тулы (данные OpenStreetMap через Overpass API) и выбирает самый быстрый маршрут без пересадок — где сесть, сколько ехать и где выйти. Интервал движения задаётся в настройках (расписаний в открытых данных нет).
- **Пробки и парковка по времени суток**: профиль пробок в баллах 0–10 по получасам (будни / суббота / воскресенье). В будни пик в 7:30 (дорога ≈ в 1,7 раза дольше), к 9:00 уже ≈ 1,2, вечерний пик в 17:30; в субботу почти пусто; понедельник утром и пятница вечером тяжелее. Профиль можно поправить вручную, а после поездки на машине — указать, сколько реально ехал, и пробки в это время подстроятся сами. Автобусы и троллейбусы тоже стоят в пробках (трамвай почти нет). Время на парковку зависит от корпуса и часа: у главного корпуса к 9 утра — до 15 минут.
- **Погрешность расчёта** настраивается: 0 / 10 / 20 / 30 % к времени в пути.
- **Сам определяет корпус** по аудитории (Гл.-403 → главный, 9-306 → корпус 9, Спорткорп-18 → спортивный корпус) — адреса 16 корпусов ТулГУ встроены. На машине маршрут строится до нужного корпуса, на автобусе добавляется путь пешком от остановки до корпуса.
- Учитывает чётные и нечётные недели для пар, добавленных вручную.
- Считает время выхода:
  - **автобус**: время до остановки, запас на ожидание, время в пути, путь от остановки; выбирает последний автобус, на котором успеваешь, и показывает запасной;
  - **машина**: маршрут по карте (OSRM), коэффициент пробок, время на парковку.
- Берёт прогноз погоды на время дороги и при гололёде, снегопаде, ливне или грозе автоматически выходит раньше и объясняет почему.
- Подсказывает одежду по ощущаемой температуре, осадкам, ветру и УФ-индексу, показывает предупреждения об опасной погоде.
- Напоминает о выходе: уведомлениями, кнопкой «В Google Календарь» (событие открывается сразу в календаре) и всей неделей через «Поделиться» в приложение календаря.
- Работает без интернета (последний прогноз сохраняется), устанавливается на телефон как приложение.
- Данные хранятся только на устройстве, регистрации и сервера нет.

## Как запустить на компьютере

Самый простой способ — открыть `index.html` в браузере.
Чтобы работали установка как приложения и офлайн-режим, нужен локальный сервер:

```
python -m http.server 8080
```

и открыть http://localhost:8080

## Как выложить сайт в интернет (GitHub Pages, бесплатно)

1. Зарегистрироваться на github.com и создать репозиторий, например `uspeyu` (Public).
2. Нажать **Add file → Upload files** и перетащить всё содержимое этой папки (не саму папку). Нажать **Commit changes**.
3. Открыть **Settings → Pages**, в разделе *Branch* выбрать `main` и папку `/ (root)`, нажать **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ИМЯ.github.io/uspeyu/`.

## Как сделать приложение

**Вариант 1 — установить сайт как приложение (1 минута).**
- Android, Chrome: открыть сайт → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
- iPhone, Safari: открыть сайт → **Поделиться** → **На экран «Домой»**.

Появится иконка «Успею», приложение открывается на весь экран без адресной строки и работает офлайн.

**Вариант 2 — получить файл APK для Android.**
1. Открыть https://www.pwabuilder.com
2. Вставить адрес сайта с GitHub Pages и нажать **Start**.
3. **Package For Stores → Android → Generate Package** → скачать архив.
4. В архиве будет файл `.apk` — его можно установить на телефон (разрешить установку из неизвестных источников) или показать на защите.

## Как пользоваться

1. **Пары** — ввести номер группы (например, 221351) и нажать «Загрузить». Расписание обновляется само раз в 12 часов.
2. **Дорога** — выбрать автобус или машину, указать адрес дома, для автобуса — интервал или точное время отправлений со своей остановки.
3. **Настройки** — проверить дату начала семестра и время пар, включить уведомления.
4. **Сегодня** — время выхода, маршрут по шагам, погода и одежда. Кнопка «Добавить в календарь» создаёт напоминания на неделю вперёд.

> Время пар по умолчанию — как в ТулГУ: 7:45, 9:40, 11:35, 13:40, 15:35, 17:30. Если в вашем корпусе другое — поменяйте в настройках.

## Как считается время выхода

```
прийти к  = начало первой пары − «прийти заранее»
погода    = +10 мин гололёд, +6/+12 снег, +3/+6 дождь/ливень, +5 гроза
             (на машине ×1,5, максимум +30 мин)

автобус:  подходит последний автобус, у которого
          отправление + время в пути + погода + путь до аудитории ≤ «прийти к»
          выход = отправление − путь до остановки − ожидание

машина:   выход = «прийти к» − время по карте × пробки − погода − парковка
```

## Устройство проекта

```
index.html            страница и нижнее меню
css/style.css         оформление (светлая и тёмная тема)
js/core.js            логика: расписание, недели, погода, одежда, расчёт выхода, календарь
js/api.js             запросы: Open-Meteo (погода), OpenStreetMap (адреса), OSRM (маршрут)
js/app.js             интерфейс, уведомления, хранение данных
sw.js                 офлайн-режим и уведомления
manifest.webmanifest  описание приложения для установки
icons/                иконки приложения
tests/core.test.js    автотесты логики
```

Внешние сервисы бесплатные и работают без ключей.

Сайт ТулГУ не разрешает браузеру загружать расписание с чужих сайтов (нет CORS), поэтому запрос идёт через прокси: сначала напрямую, потом через свой прокси из настроек (если указан), потом через публичные r.jina.ai и api.allorigins.win. Для надёжности можно сделать свой бесплатный прокси на Cloudflare Workers — файл `proxy/worker.js`, в настройках указать `https://ИМЯ.workers.dev/?url={url}`.
