# Успею

**Сайт:** https://vkysnasa1.github.io/Uspey/

Утром не хочется считать в уме, когда выходить, чтобы успеть к первой паре. «Успею» делает это за студента ТулГУ: берёт расписание группы с сайта университета, смотрит погоду и пробки, подбирает автобус или считает дорогу на машине и говорит одно время — во сколько выйти из дома. Заодно подсказывает, что надеть, и напоминает о выходе.

Проект по дисциплине «Управление проектной деятельностью», ТулГУ.
Команда: Комерилов Григорий (руководитель, интерфейс, уведомления), Кузнецов Артем (данные и логика расчёта), Гончаров Иннокентий (аналитика, дизайн, тестирование), Харитонов Илья.

## Что умеет

**Расписание.** Вводишь номер группы, и пары на весь семестр загружаются с tulsu.ru/schedule: время, аудитории, преподаватели. Видно сразу две недели, нечётную и чётную. Чужие пары (другая подгруппа по языку, физра не в твоё время) можно скрыть: на один день, по чётным или нечётным неделям или насовсем. Скрытие учитывает преподавателя, так что пара твоей подгруппы останется. Свои занятия вроде ВУЦ или секции добавляются вручную, на все недели или через одну.

**Корпус.** По аудитории приложение понимает, куда ехать: «Гл.-403» — главный корпус, «9-306» — девятый, «Спорткорп-18» — спортивный. Адреса 16 корпусов встроены.

**Дорога на транспорте.** По адресу дома находит ближайшие остановки и маршруты автобусов, троллейбусов и трамваев Тулы из OpenStreetMap и выбирает самый быстрый без пересадок: где сесть, сколько ехать, где выйти. Путь пешком до остановки и от остановки до корпуса считается по настоящим тротуарам. Расписаний транспорта в открытых данных нет, поэтому интервал задаётся вручную, и у каждого маршрута он может быть свой.

**Дорога на машине.** Маршрут по карте (OSRM), пробки и время на парковку. Пробки задаются в баллах от 0 до 10 по получасам, отдельно для будней, субботы и воскресенья. По умолчанию в будни пик в 7:30 (9 баллов, дорога почти вдвое дольше), к 9:00 около 5, днём 3–4, вечерний пик в 17:30. Если после поездки написать, сколько реально ехал, профиль сам подстроится. Парковка у главного корпуса к девяти утра занимает до 15 минут, у дальних корпусов меньше.

**Погода и одежда.** Прогноз берётся на время дороги. В гололёд, снегопад, ливень или грозу выход сдвигается раньше, и приложение пишет почему. Одежда подбирается по ощущаемой температуре, осадкам, ветру и УФ-индексу.

**Ракетная опасность.** Кнопка на главном экране сдвигает выход раньше на выбранный запас (транспорт может встать, связь пропасть). Через 12 часов режим выключается сам.

**Напоминания.** Три способа, от самого надёжного:
- Telegram-бот пишет за N минут до выхода и в момент выхода, даже если приложение закрыто. Боту уходит только время и название пары, адреса остаются на телефоне. Бота нужно один раз развернуть, см. ниже.
- Календарь: кнопка «В Google Календарь» для ближайшей поездки или файл на всю неделю. Будильник календаря срабатывает без интернета.
- Уведомления браузера приходят, только пока приложение открыто. Свёрнутое приложение телефон усыпляет за несколько минут, так что утром на них лучше не рассчитывать.

**Остальное.** Несколько своих адресов («Дом», «Общежитие», «Работа») и переключение одной кнопкой. Перенос всех настроек на телефон ссылкой. Погрешность расчёта 0, 10, 20 или 30 %. Работает без интернета, ставится на телефон как приложение. Регистрации нет, данные хранятся на устройстве.

## Как считается время выхода

```
прийти к  = начало первой пары − «прийти заранее» − запас на ракетную опасность
погода    = +10 мин гололёд, +6/+12 снег, +3/+6 дождь/ливень, +5 гроза
             (на машине ×1,5, максимум +30 мин)

транспорт: подходит последний рейс, у которого
           отправление + время в пути × пробки + погода + путь до аудитории + погрешность ≤ «прийти к»
           выход = отправление − путь до остановки − ожидание

машина:    выход = «прийти к» − время по карте × пробки − погода − парковка − погрешность
```

Время пар по умолчанию как в ТулГУ: 7:45, 9:40, 11:35, 13:40, 15:35, 17:30. Его можно поменять в настройках. Начало семестра, от которого считается чётность своих пар, берётся из расписания ТулГУ.

## Запустить у себя

Проще всего открыть `index.html` в браузере. Чтобы работали установка на телефон и офлайн-режим, нужен локальный сервер:

```
python -m http.server 8080
```

и затем http://localhost:8080

## Поставить на телефон

- Android, Chrome: открыть сайт → меню ⋮ → «Установить приложение».
- iPhone, Safari: открыть сайт → «Поделиться» → «На экран „Домой“».

Нужен файл APK для Android? На https://www.pwabuilder.com вставь адрес сайта, нажми Start, затем Package For Stores → Android → Generate Package. В скачанном архиве будет `.apk`.

## Telegram-бот напоминаний

Бот живёт в папке `bot/`. Это Cloudflare Worker с маленькой базой D1, бесплатного тарифа хватает с запасом. Приложение само считает время и отправляет боту готовые напоминания на неделю вперёд, а бот раз в минуту проверяет, кому пора написать.

1. В Telegram написать [@BotFather](https://t.me/BotFather) → `/newbot`, придумать имя. Он пришлёт токен.
2. На dash.cloudflare.com: **Storage & Databases → D1 → Create**, имя `uspey-bot`. Открыть базу → **Console**, вставить содержимое `bot/schema.sql`, выполнить.
3. **Workers & Pages → Create → Worker**, имя `uspey-bot`, вставить код `bot/worker.js`, Deploy.
4. В настройках воркера:
   - **Bindings → D1 database**: имя переменной `DB`, база `uspey-bot`;
   - **Variables and Secrets**: `BOT_TOKEN` (токен от BotFather, тип Secret), `SETUP_KEY` (Secret, 32+ латинских букв и цифр, например из генератора паролей без спецсимволов), `ORIGIN` = `https://vkysnasa1.github.io`;
   - **Triggers → Cron Triggers**: `* * * * *` (каждую минуту).
5. Открыть в браузере `https://uspey-bot.ИМЯ.workers.dev/setup?key=ТВОЙ_SETUP_KEY`. Должно ответить `"ok": true`.
6. Вписать адрес воркера в `js/app.js` в строку `const BOT_URL = ''`, чтобы кнопка появилась у всех. Или каждый может вписать его сам в настройках приложения.

Через командную строку то же самое делается с `bot/wrangler.toml` и `npx wrangler deploy`.

### Чтобы ключи не украли

- **Токен бота** хранится только в секретах Cloudflare. В репозитории, в приложении и в ответах воркера его нет. Никуда его не вставляй, кроме поля `BOT_TOKEN`. Если всё-таки засветился, напиши BotFather `/revoke`, получи новый и замени секрет.
- **SETUP_KEY** проверяет, что сообщения в бота пришли от настоящего Telegram: Telegram кладёт его в заголовок каждого запроса. Ссылку `/setup?key=...` открой один раз и никому не показывай.
- **Ключ устройства** создаётся в приложении: 144 случайных бита, подобрать нереально. Он есть только в памяти телефона и в команде `/start` в твоём чате с ботом. В ссылку переноса и в файл копии он не попадает. Даже с ним можно лишь поменять напоминания в твоём чате: прочитать ничего нельзя, ссылки и @упоминания из текста вырезаются, запросов не больше 60 в час. Если что, нажми в настройках «Отключить» и привяжи заново, будет новый ключ.
- Адресов, группы и настроек на сервере нет совсем, так что утечь им неоткуда.

## Расписание ТулГУ и прокси

Сайт ТулГУ не отдаёт расписание чужим сайтам (нет CORS), поэтому приложение опрашивает сразу несколько путей и берёт первый ответ: напрямую, свой прокси из настроек, публичные r.jina.ai, allorigins, corsproxy и codetabs. Если не сработало ничего, берётся копия из `data/tulsu/`. Её каждые 4 часа обновляет GitHub Actions (`.github/workflows/tulsu.yml`, группы перечислены в `data/tulsu/groups.txt`). Если расписание долго не меняется, Action раз в 50 дней делает пустой коммит, иначе GitHub выключил бы запуск по расписанию через 60 дней тишины.

Свой прокси можно поднять бесплатно на Cloudflare Workers из файла `proxy/worker.js` и указать в настройках `https://ИМЯ.workers.dev/?url={url}`. Он пропускает только запросы к расписанию ТулГУ.

## Из чего состоит

```
index.html            страница и нижнее меню
css/style.css         оформление, светлая и тёмная тема
js/core.js            логика без интерфейса: расписание, недели, погода, одежда, пробки, расчёт выхода, календарь
js/api.js             запросы: Open-Meteo, OpenStreetMap, OSRM, расписание ТулГУ, бот
js/app.js             интерфейс, хранение данных, уведомления
sw.js                 офлайн-режим
bot/                  Telegram-бот напоминаний (Cloudflare Worker + D1)
proxy/worker.js       свой прокси для расписания ТулГУ
scripts/              скрипт копии расписания для GitHub Actions
tests/core.test.js    автотесты логики
```

Внешние сервисы бесплатные и работают без ключей: погода Open-Meteo, адреса и остановки OpenStreetMap (Nominatim, Overpass), маршруты OSRM.

## Тесты

```
node --test tests/core.test.js
```

Проверяют разбор времени и расписания ТулГУ, чётность недель, выбор автобуса и интервалы по маршрутам, поправки на погоду, расчёт для машины, пробки, особые случаи (нет пар, ни один автобус не успевает), одежду, файл календаря и напоминания для бота.
